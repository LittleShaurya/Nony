# NYC Rush

A fast, self-contained browser racing game set in a rainy New York City street.

## Features

- Long 3.2-mile race against a highly skilled adaptive rival
- Oncoming traffic that causes speed penalties on collision
- NYC-inspired skyline, shops, pedestrians, crowds, and cheering spectators
- Keyboard and touch controls
- No build step or external dependencies

## Play

Open `index.html` in a browser, or serve the repository locally:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Controls

- **Left / Right** or **A / D** — steer
- **Up** or **W** — accelerate
- **Down** or **S** — brake
- Touch drag — steer; touch hold — accelerate
